# speedtest

Скрипт-замерятель скорости интернета. Принимает адрес тяжёлого файла (например, большой картинки), делает к нему **10 последовательных запросов**, дожидается полного скачивания каждого и выводит:

- время и скорость каждого запроса;
- среднее время запроса;
- общий объём скачанных данных;
- среднюю скорость в **Мбит/с** (и МБ/с).

Зависимостей нет — только стандартная библиотека Python.

## Требования

Python 3.9+

## Запуск

```bash
git clone https://github.com/SaynoMore22/speedtest.git
cd speedtest
python speedtest.py https://upload.wikimedia.org/wikipedia/commons/3/3f/Fronalpstock_big.jpg
```

Если URL не указан, используется большая картинка с Wikimedia (~14,7 МБ):

```bash
python speedtest.py
```

### Параметры

| Параметр | По умолчанию | Описание |
|---|---|---|
| `url` | картинка с Wikimedia | адрес файла для скачивания |
| `-n`, `--requests` | `10` | количество запросов |
| `-t`, `--timeout` | `60` | таймаут одного запроса, сек |

## Как считается

- Время запроса — от отправки запроса до получения последнего байта тела ответа.
- Скорость = `суммарные байты × 8 / суммарное время / 10⁶` (Мбит/с). Единицы десятичные: 1 МБ = 10⁶ байт.
- Запросы с ошибкой выводятся в консоль и не учитываются в итоге.
